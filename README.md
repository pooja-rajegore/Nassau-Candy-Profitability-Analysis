# Product Line Profitability & Margin Performance Analysis
## Project Overview
This project analyzes product profitability, gross margin performance, division efficiency, and cost structure for Nassau Candy Distributor.

## Tools Used
- Python
- Pandas
- PostgreSQL
- SQL
- Streamlit
- Plotly

## Features
- Product Profitability Analysis
- Division Performance Analysis
- Pareto Analysis
- Cost Diagnostics
- Interactive Dashboard
